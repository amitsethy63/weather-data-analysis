# 🌦️ Weather Data Analysis

## 📌 Project Overview
This project analyzes historical weather data for Bhubaneswar, Odisha, using the Open-Meteo Archive API. It uses Python to collect, process, analyze, and visualize weather information for the year 2025.

## 🎯 Objectives
- Retrieve historical weather data using an API.
- Analyze maximum, minimum, and average temperatures.
- Calculate total rainfall.
- Find monthly average temperatures.
- Visualize daily and monthly temperature trends.

## 🛠️ Technologies Used
- Python
- Requests
- Pandas
- Matplotlib
- Seaborn
- Open-Meteo Archive API

## 📊 Key Features
- Automated weather data collection.
- Data processing and CSV export.
- Statistical analysis of temperature and rainfall.
- Daily temperature trend visualization.
- Monthly average temperature comparison.

## 📁 Project Files
- `weather_analysis.py` – Main Python script.
- `weather_data.csv` – Collected weather dataset.
- `weather_analysis.png` – Combined temperature charts.
- `requirements.txt` – Required Python libraries.

## ⚙️ How to Run

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Python script:

   ```bash
   python weather_analysis.py
   ```
   
## 📡 Data Source
Open-Meteo Historical Weather API: https://open-meteo.com/
